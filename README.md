# Anwar Omarchy Theme

A theatrical burgundy, teal, ivory and brass palette inspired by the satirical stage world associated with Anwar Maqsood, with four original wallpapers. Includes optional Liquid Glass Hyprland styling.

## Install

Copy this repository into `~/.config/omarchy/themes/anwar` and select it with `omarchy theme set anwar`.

Choose one of the bundled wallpapers with `omarchy theme bg set <path>`.

## Liquid Glass window styling

`hyprland.lua` is included as an optional reference. The Omarchy theme installer does not install Lua files; to apply it, review and manually merge its settings into your Hyprland user configuration.

## Backgrounds

Four original 3:2 landscape wallpapers are in `backgrounds/`. `preview.png` shows the first wallpaper cropped to 16:9 for the theme listing.
